# Roadmap

1. Completed foundation: offline CLI, explicit memory persistence, expiry and regression tests.
2. Next: design a typed event interface and an allowlist of capabilities; exercise it using synthetic events.
3. Later: add a local-model adapter, with network-disabled tests and clear failure behavior.
4. Voice and vision: define consent, visible recording indicators and data retention before attaching sensors.
5. Mobile/API: authentication and authorization must precede any remote command interface.

These are planned milestones without promised delivery dates. The security module will be scoped separately to owned or explicitly authorized environments.
