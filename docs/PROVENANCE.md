# Provenance

STEEL imports OpenJarvis (Apache-2.0, https://github.com/open-jarvis/OpenJarvis) from the pinned install at commit `108d257188cbad85f2e50209d9a61669ea4dec33`. Imported code is not copied into this repository and is not modified.

Any file ported (copied and adapted) from OpenJarvis must start with a header giving its source path, the commit, the Apache-2.0 license and what changed. It must also get a row here.

| STEEL file | OpenJarvis source path | Commit | What changed |
| --- | --- | --- | --- |
| `steel/security/policy.py` | `src/openjarvis/security/capabilities.py` (`CapabilityPolicy._check_python`, `AgentPolicy`, `CapabilityGrant`, and the policy-file validation in `_load_file`) | `108d257188cbad85f2e50209d9a61669ea4dec33` | Pure Python only (no Rust). **Inverted from open-by-default to deny-by-default**: an unknown agent, an unmatched capability or any error is a deny, and the `_default` fallback agent is removed. Fixed capability vocabulary; exact matching instead of `fnmatch`; path grants matched on resolved path components; sensors never covered by a wildcard; every decision written to a names-only audit log; strict policy-file validation. Details: docs/POLICY.md |

`steel/security/executor.py` subclasses `openjarvis.tools._stubs.ToolExecutor` and contains no copied code. `steel/tools/microphone.py` subclasses `openjarvis.tools._stubs.BaseTool` and contains no copied code.

**Voice (Phase 2c) copies nothing from OpenJarvis and has no row above.** `steel/voice/` deliberately does not import `openjarvis.speech` (see docs/VOICE.md section 2: its discovery can choose a cloud backend, its Faster-Whisper backend writes the audio to a temp file and takes a model name that may be downloaded, and importing the package loads the cloud backends too). It reuses OpenJarvis only for the tool base classes and `ToolExecutor`. Third-party components it uses, with the licenses read from the installed package metadata and the Hugging Face model cards on 2026-10-24: `faster-whisper` 1.2.1 (MIT), `ctranslate2` 4.8.3 (MIT), `onnxruntime` 1.31.0 (MIT), `av` 19.0.2 (BSD-3-Clause), `tokenizers` 0.23.3 (Apache-2.0 classifier), `soundfile` 0.14.0 (BSD-3-Clause) and `sounddevice` 0.5.6 (MIT) (the last two arrive with the `[speech]` extra and are not imported by STEEL); models `Systran/faster-whisper-small` and `Systran/faster-whisper-base` (MIT), revisions and checksums in docs/VOICE.md section 3. `arecord` (alsa-utils) is run as a separate program. `steel/facts.py` subclasses `openjarvis.memory.store.LocalFactStore` and uses its private members. It contains no copied code.
